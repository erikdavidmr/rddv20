POS: Integración Terminal Verifone vía Middleware

Este módulo permite que el Punto de Venta de Odoo se comunique con una terminal de pago Verifone usando un middleware sobre IP.

Características

  • Envío automático del monto a pagar desde el POS a la terminal Verifone.
  • Recepción del resultado (aprobado/rechazado) mediante webhook.
  • Actualización automática del estado de pago en Odoo POS.
  • Soporte para múltiples terminales mediante configuración por método de pago.

Configuración en Odoo

  1. Ve a Punto de Venta > Configuración > Métodos de Pago.
  2. En un método de pago de tipo tarjeta, selecciona un diario de tipo Bancario.
  3. En el campo Terminal de pago, selecciona: Verifone Terminal (LAN Middleware).
  4. Completa los campos:
    • Verifone Middleware IP: IP local o pública del servicio middleware.
    • Verifone Middleware Port: Puerto TCP abierto (por defecto 5000).

Configuración del parámetro de seguridad

En Ajustes > Parámetros Técnicos > Parámetros del sistema agrega:

  • Clave: verifone.webhook.token
  • Valor: 123456789 (o el token que desees)

Configuración del Middleware

El middleware es un servicio HTTP que debe estar instalado y ejecutándose en una máquina con Windows o Linux accesible desde el servidor Odoo.

  • El middleware escucha POST en /pay para recibir los datos desde el POS.
  • Después de procesar el pago en la terminal física, el middleware envía el resultado a Odoo mediante el webhook /verifone/webhook_pago.
  • La URL del webhook y el token deben coincidir con los configurados en Odoo.

Archivo de configuración ejemplo (mock_verifone_middleware.py)

ODOO_WEBHOOK_URL = "http://tu-odoo.com/verifone/webhook_pago"
VERIFONE_TOKEN = "123456789"

Requisitos de red

  • El middleware debe tener acceso de red al servidor de Odoo (y viceversa).
  • Si Odoo está en la nube y el middleware en una red local, se requiere redireccionamiento de puertos.

Detalles Técnicos

Datos enviados desde Odoo POS al middleware

Odoo envía al middleware una petición POST con el siguiente JSON:

{
  "amount": 123.45,
  "reference": "POS/2025/0012",
  "pos_id": "Caja 1",
  "LocalPaymentID": "POS/2025/0012",
  "InvoiceID": "POS/2025/0012",
  "Lane": "Caja 1",
  "Venue": "Caja 1",
  "paymentline_uuid": "c0a80123-4567-890a-bcde-000000000000",
  "merchant_order_id": "2025-05-23T10:32:00Z--42--c0a80123-4567-890a-bcde-000000000000",
  "external_reference": "42_10_c0a80123-4567-890a-bcde-000000000000"
}

Respuesta esperada desde el middleware (Webhook)

El middleware debe enviar el resultado a Odoo con este JSON:

{
  "InvoiceID": "POS/2025/0012",
  "LocalPaymentID": "POS/2025/0012",
  "amount": 123.45,
  "status": "approved",
  "card_type": "Visa",
  "merchant_order_id": "2025-05-23T10:32:00Z--42--c0a80123-4567-890a-bcde-000000000000",
  "paymentline_uuid": "c0a80123-4567-890a-bcde-000000000000",
  "auth_code": "TX123456789",
  "external_reference": "42_10_c0a80123-4567-890a-bcde-000000000000"
}
