Módulo Core RDD: Customizaciones POS & Inventario

El pilar fundamental de personalización para el sistema RDD. Integra características avanzadas de cálculo de PUC Multicompañía, notificaciones por listas de precios, y control de seguridad en el Punto de Venta.

Alcances y Funcionalidades

🏢 PUC Multicompañía Avanzado

El cálculo del Precio Único de Costo (PUC) está aislado por compañía, asegurando que las valoraciones de inventario y márgenes en el Punto de Venta respeten estrictamente el entorno Multi-Cía.

🔐 Control de Cierre POS (Manager PIN)

Intercepción del cierre de sesión para exigir un PIN de Manager en caso de descuadres, previniendo cierres no autorizados que generen diferencias contables injustificadas.

📧 Alertas y Notificaciones por Correo

El sistema incluye crons automáticos que disparan correos a los administradores cuando hay listas de precios actualizadas o se detectan sesiones de caja que quedaron abiertas.

🏷️ Extensiones UI de Productos

Integra nuevos campos de permisos especiales en el catálogo, permitiendo un bloqueo selectivo de quienes pueden editar los costos dinámicos de los productos.

⚙️ Impacto Técnico y Código

  • Backend POS: Modificación de _load_pos_data para inyectar campos variables multicompañía directo al caché de sesión.
  • Motor Contable: Cálculo en product.template iterando históricamente las últimas 3 órdenes de compra para deducir dinámicamente el PUC unitario y registrar un histórico en Log.
  • Frontend OWL: Parches extensos en los componentes ProductProduct y ClosePosPopup, inyectando flujos de validación adicionales antes de ejecutar las promesas de red.
